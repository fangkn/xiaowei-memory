# 后续计划

以下为待完善方向，不是已实现功能，也不承诺交付日期。优先保证备份可核对、错误可定位和已有数据可恢复。

## 发布质量

- 在独立 Chrome / Edge 配置中完成安装、图片授权、临时 Referer 规则、Service Worker 重启、OPFS 与真实下载的端到端验收；公开浏览器版本和结果边界。
- 持续补充脱敏的页面结构与历史接口 fixture，覆盖微博结构变化、长文、旧表情和不可访问内容。
- 记录运行时依赖与字体的来源版本、哈希和加工过程，补齐可复现的第三方产物构建流程。
- 根据实际验证结果完善支持的浏览器版本范围和发布检查，提供明确版本的可下载安装包。

## 数据与恢复

- 提供原始记录的 JSON / ZIP 导出与校验后导入，让更换浏览器、安装路径或设备时可以迁移；设计格式版本及兼容策略。
- 增加记录、图片缓存、临时 PDF / ZIP 的空间统计和按范围清理，清理前说明对恢复任务的影响。
- 完善异常退出、磁盘空间不足及临时文件被回收后的恢复提示。

## 诊断与使用体验

- 增加一键复制的脱敏诊断，默认移除账号标识、原文链接和图片 URL 查询参数；敏感细节仅在本机供用户排查。
- 优化单月大文件的提示和可选图片压缩，在保持月度文件组织的前提下减少导出体积。
- 持续改进键盘操作、焦点管理和屏幕阅读器提示。

现阶段不计划通过远程服务代存登录信息，也不将“已遍历月份”表述为“已备份全部历史”。
