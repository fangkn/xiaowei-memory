# 测试数据约定

测试中的作者、UID、帖子 ID、正文与媒体文件名均使用合成示例，不代表真实账号或真实帖子。`1000000001`、`1000000002` 等只是满足解析规则的测试值；不要为运行测试访问这些账号。

`weibo-modern-dom.sanitized.html` 保留观察到的页面结构与类名，已替换作者、内容及地址。单元测试的 HTTP 响应由测试提供；浏览器测试使用静态页面，不登录微博。

一些地址带有 `token=private`、`user:secret` 等字面量，用于验证去敏和拒绝不安全 URL；它们不是凭据。图片 URL 使用新浪域名以测试允许列表，媒体字节使用内嵌或合成数据。

添加复现案例时请保留最小结构，并替换 UID、昵称、原文、图片文件名、URL 查询参数及个人目录。不要提交 Cookie、浏览器配置、真实备份文件或私人照片。
